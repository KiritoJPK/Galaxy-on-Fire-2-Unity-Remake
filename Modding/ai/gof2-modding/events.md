# Galaxy on Fire 2 Remake: event graph nodes and commands

Generated by GoF2 > Build > Modding AI Reference from the node classes. Quests, bar missions, cutscenes and multiplayer
events are `.gof2event` graphs built in the Unity Editor (Assets > Create > GoF2 > Event Graph; templates under Event
Graph From Template): give the user a recipe of nodes with these exact names, option values and wires. What the nodes do
together is explained in `guide.md` ("Quests and bar missions" and the multiplayer "Events"); this file lists every node,
option and port.

Wires: the **Flow** arrows run the steps in order (a node's unnamed flow output is Next, named ones are branches; a
node without a flow input starts a flow of its own). Data wires carry Number / Text / Yes/No values, **Players** (who a
command acts on; or type a selector into the Players port) and **Orbit** (a station, from Get Orbit). Options are set on
the node itself; an input port is typed into or wired. The blackboard's Number variables are read by dragging them in
and set with Set Variable (Input variables are the event's settings). Texts may hold `{expression}` parts, `%player%`,
`%trigger%`, `%victim%` and `[voice <clip>]` (clips in voices.md).

Expressions (If, While, Wait Until, Set Variable, `{...}` in texts, Starts when, `available`): numbers, variables, + - * /,
== != < <= > >=, and / or / not, random(a, b), min, max, floor, count(<players>), alive(ship name), distance(ship name, x,
y, z), the state words enemies, ships, players, inspace, docked, dead, time, toppoints, missionstation, and this game's
campaign, credits, rank, station, system, ship, kills, cargo(item), has(item), visited(station), quest(name),
option(mod:id), won(main | valkyrie | supernova), systemsvisited.

### Player selectors

- `@a`: everyone
- `@s`: yourself
- `@p`: the nearest player
- `@r`: a random player
- `@alive`: everyone alive in space
- `@survivors`: the event's players never destroyed
- `@team`: the event's players (a bar mission's team)
- `@space`: everyone in space
- `@docked`: everyone docked
- `@dead`: everyone destroyed in space
- Any selector narrowed to one orbit: `@alive[orbit=78]`, `@r[orbit=Var Hastra]` (in its space or docked at its station).
- In single player every selector is the player.
